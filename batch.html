Type rows, or paste from Excel / Google Sheets (Cmd+V anywhere) — column order: Date · Amount · Description · Category · Paid by · Split. Missing columns use sensible defaults. Tab moves across, Enter moves down — a fresh row always waits at the bottom, so just keep typing (or use “Add rows” for a big batch). Empty rows are ignored; red = a problem (skipped on save); amber = possible duplicate (same amount within ±3 days, any book) — the match is shown in a strip under the row, where you can Remove row or mark it Not a duplicate.
